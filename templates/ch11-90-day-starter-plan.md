# Chapter 11 Ninety-Day Starter Plan

**Artifact class:** illustrative template

The windows below organize work. They do not establish readiness or require a
phase transition. If a required gate is unsatisfied, unverified, or expired,
the team follows the declared narrow, hold, or stop response.

## Days 1–30 — define the work and stop line

- Freeze the eligible population, exclusions, current workflow, and baseline.
- Write the pilot contract and human authority charter.
- Record source, security, privacy, ownership, and cost boundaries.
- Declare the non-AI alternative and stop conditions.
- Run the first continue, narrow, hold, or stop review.

## Days 31–60 — make the read-only path fail visibly

- Build only the selected evidence path.
- Bind identity, purpose, audience, clocks, source health, lineage, and versions.
- Exercise denial, staleness, absence, conflict, schema drift, source loss,
  injection, retry, audit loss, and budget exhaustion.
- Preserve native-tool access, correction, and manual continuation.

## Days 61–90 — evaluate in shadow only if earned

- Preserve every eligible, no-answer, indeterminate, and unevaluable case.
- Separate recommendation, responder decision, and later adjudication.
- Review uncertainty, subgroup behavior, transferred work, source health, cost,
  privacy, security, and version stability.
- Exercise hold, demotion, fallback, correction, and retirement.
- Run the day-90 continue, narrow, hold, or stop governance review.
